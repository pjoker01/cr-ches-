# PJ App Store

Public, mobile-first catalogue for PJ Web Development apps. This project is deliberately separate from the existing PJ Business OS and other customer apps.

## Deploy
- Framework: Other / static site
- Root directory: repository root
- Build command: none
- Output directory: `.`

## Notes
- App destinations are explicitly defined in `index.html`; verify links before production.
- PJ Command is marked as in development and has no invented destination.
- PWA manifest and service worker are included. Install prompts depend on browser support and secure hosting.
- No user data, credentials, or customer records are stored in this catalogue.
